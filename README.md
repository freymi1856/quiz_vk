# Quizluv

Рабочий MVP веб-приложения для интерактивных квизов и опросов в реальном времени.

## Что умеет

- регистрация и вход для организаторов и участников;
- личный кабинет с историей созданных и пройденных квизов;
- создание квизов с настройками времени, категорий и правил;
- вопросы с текстом или изображением, одиночный и множественный выбор;
- запуск live-сессии с подключением участников по коду комнаты;
- синхронный показ вопросов через WebSocket;
- подсчет баллов, лидерборд и сохранение результатов.

## Технологии

- Frontend: React + Vite;
- Backend: Node.js + Express;
- Realtime: Socket.IO;
- Хранение данных: JSON file database в `server/data/store.json`.

## Запуск

1. Установите Node.js LTS с https://nodejs.org/
2. Установите зависимости:

```bash
npm install
```

3. Запустите frontend и backend:

```bash
npm run dev
```

4. Откройте приложение:

```text
http://localhost:5173
```

Backend API будет доступен на `http://localhost:4000`.

## Быстрый сценарий проверки

1. Зарегистрируйтесь как организатор.
2. Создайте квиз и добавьте несколько вопросов.
3. Нажмите "Запустить" и скопируйте код комнаты.
4. В другом браузере или вкладке зарегистрируйтесь/войдите как участник.
5. Введите код комнаты, отвечайте на вопросы.
6. Организатор переключает вопросы, после завершения все видят лидерборд.
