# Quizluv: краткая пояснительная записка

## Цель проекта

Quizluv — веб-приложение для проведения интерактивных опросов и квизов в реальном времени. Сервис позволяет организатору создать набор вопросов, запустить live-сессию и дать участникам код комнаты для подключения.

## Обоснование выбора технологий

Frontend реализован на React и Vite, потому что React подходит для динамических интерфейсов с частым обновлением состояния, а Vite быстро запускает проект в режиме разработки.

Backend реализован на Node.js и Express. Такой стек хорошо подходит для JavaScript-проекта, так как frontend и backend пишутся на одном языке.

Для realtime-взаимодействия используется Socket.IO. Он упрощает работу с WebSocket: участники автоматически получают новый вопрос, обновления количества ответов и итоговый лидерборд.

Данные MVP сохраняются в JSON file database `server/data/store.json`. Для учебного прототипа этого достаточно, при необходимости хранилище можно заменить на SQLite или PostgreSQL, потому что логика доступа к данным вынесена в отдельный модуль.

## Основные функции

- регистрация и авторизация пользователей;
- роли: организатор и участник;
- создание и редактирование квизов;
- настройка категории, правил и времени на вопрос;
- вопросы с текстом или изображением;
- одиночный и множественный выбор ответа;
- запуск комнаты с уникальным кодом;
- подключение участников к активному квизу;
- синхронный показ вопросов;
- прием ответов только во время демонстрации вопроса;
- подсчет баллов и определение лидеров;
- история проведенных и пройденных сессий.

## Этапы разработки

1. Спроектирована структура данных: пользователи, квизы, вопросы, варианты ответов, live-сессии и ответы.
2. Создан backend на Express с REST API для авторизации, квизов и истории.
3. Добавлен realtime-слой Socket.IO для комнат, переключения вопросов и отправки ответов.
4. Реализован frontend на React: кабинет, редактор квиза, вход по коду, live-комната и лидерборд.
5. Подготовлены инструкции запуска и проектная документация.

## Возможные улучшения

- заменить JSON-хранилище на PostgreSQL или SQLite;
- добавить загрузку изображений на сервер вместо ссылки;
- добавить восстановление активной комнаты после перезагрузки страницы;
- добавить экспорт результатов в CSV;
- оформить макеты в Figma на основе готового интерфейса.
